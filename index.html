knobs.

knob (n.): a default parameter or setting in a dependency or project that can change silently between versions and change how your system behaves.

You didn't change your code. You bumped a version or pulled upstream, and now the robot brakes harder, the server trusts a different proxy, or the feed ranks likes differently. A default moved, and no changelog said so.

Why knobs matter

  • Silent. They change in commits called "update params". Release notes rarely list them.
  • Behavioural. A gain, threshold, timeout or weight is behaviour.
  • Inherited. Every default you didn't set is a decision someone upstream can revise.
  • Checkable. A default is a literal in a file. Diff it and you know exactly what moved, from what, to what, and in which commit.
